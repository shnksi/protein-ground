# Snapshot (eval v2)

Gzipped JSON responses from the public APIs, recorded on 23 Nov 2026 by
`evals/v2/build_questions.py`. Each file holds one URL, its HTTP status, retrieval time and
body. Eval v2 replays these so every run sees the exact records the gold answers were
computed from.
